pii-sanitizer-agent

Fail-closed PII redaction — library, CLI and prompt-sanitizing agent wrapper. Pure Python standard library. Offline. No API keys.

The idea

Most redaction scripts fail open: whatever their patterns miss sails through. For PII the costs are asymmetric — a missed card number is a breach, an over-redacted reference number is a shrug. So when detection is uncertain, this sanitizer redacts anyway and says so in the report (AMBIGUOUS_NUMBER).

Two behaviours to notice: the repeated email reuses [EMAIL_1] (same value → same token, so the text still reads coherently), and the 14-digit “support reference number” — not a real identifier — is redacted anyway. That is fail-closed working as designed. The 5-digit order number is below identifier size and is left alone.

Report format (excerpt, --report)

The report never contains raw values — only types, spans and tokens — so it is safe to log.

{
  "version": 1,
  "fail_closed": true,
  "total_findings": 12,
  "counts_by_type": {
    "EMAIL": 3, "PHONE": 2, "SSN": 1, "AADHAAR": 1, "PASSPORT": 1,
    "CARD": 1, "IBAN": 1, "SECRET": 1, "AMBIGUOUS_NUMBER": 1
  },
  "has_high_severity": true,
  "findings": [
    {"type": "EMAIL", "start": 90, "end": 111, "token": "[EMAIL_1]",
     "severity": "medium", "detector": "email"},
    {"type": "CARD", "start": 311, "end": 330, "token": "[CARD_1]",
     "severity": "high", "detector": "card_luhn"}
  ],
  "mapping": {"[EMAIL_1]": 2, "[EMAIL_2]": 1, "[CARD_1]": 1, "[SSN_1]": 1}
}

Use it

pip install -e .
python -m pii_sanitizer sanitize examples/sample.txt --report report.json

from pii_sanitizer import PromptSanitizerAgent
agent = PromptSanitizerAgent(block_on_high_severity=True)
output, report = agent.run(prompt, my_llm_fn)  # callable only sees clean text

228 pytest cases cover every detector with positive and negative cases, the fail-closed near-miss policies, overlap resolution, allowlists, unicode, adversarial obfuscation (pinned as documented limitations), the agent blocking contract, and the CLI. MIT licensed.
